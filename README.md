# ☕ Learning Java

Bem-vindo aos meus estudos em Java! Este repositório documenta a minha evolução e aprendizado com a linguagem, com foco no aprofundamento em lógica de programação, estruturas de dados clássicas e boas práticas de desenvolvimento.

## 🚀 Projetos Desenvolvidos

### 🧱 Estruturas de Dados

Implementação do zero de estruturas de dados para entender o funcionamento do armazenamento e manipulação na memória por baixo dos panos.

- **[Array](./data-structures/array/)** 📦
  - **Descrição:** Implementação da estrutura de dados baseada em vetores.
  - **Destaques:** Criação de algoritmos customizados para funcionalidades cruciais como inserção, remoção e pesquisa de elementos.
- **[Binary Tree](./data-structures/binary-tree/)** 🌳
  - **Descrição:** Implementação de uma Árvore Binária.
  - **Destaques:** Manipulação de hierarquia de dados, criação de nós parentais/filhos e lógica de travessia.
- **[Linked List](./data-structures/linked-list/)** 🔗
  - **Descrição:** Implementação de Listas Encadeadas.
  - **Destaques:** Manipulação de ponteiros e referências de memória para a construção de coleções dinâmicas sem tamanho fixo.

### 🎮 Aplicações Práticas

Projetos focados em aplicar a lógica de programação na resolução de problemas e regras de negócios.

- **[Tic-Tac-Toe](./projects/tic-tac-toe/)** ❌⭕
  - **Descrição:** O clássico Jogo da Velha por terminal.
  - **Destaques:** Lógica de turnos para dois jogadores (Offline e Online), controle dinâmico do estado do tabuleiro e algoritmos de verificação automática de vitória ou empate.

---

## 🛠️ Como executar os projetos

Como os projetos são nativos em Java, você precisará do **Java Development Kit (JDK)** instalado em sua máquina.

**Executando via IDE:**

1. Clone o repositório em sua máquina.
2. Abra a pasta raiz (`learning-java`) utilizando o **IntelliJ IDEA**, Eclipse ou VS Code.
3. Navegue até a pasta do projeto desejado (ex: `tic-tac-toe`), encontre a classe `Main.java` e clique em _Run_.
